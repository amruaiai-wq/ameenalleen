ตัวละคร "มูมู" (Moomoo) — ชุดสไปรท์แยกพื้นหลังโปร่งใส
========================================================
ไฟล์ทั้งหมดเป็น PNG พื้นหลังโปร่งใส (RGBA) ครอปชิดตัว
พร้อมนำเข้าโปรแกรมอนิเมชัน (After Effects / Spine / DragonBones /
Toon Boom / Unity / Godot ฯลฯ)

โครงสร้างโฟลเดอร์
- 00_hero_main.png       ตัวหลัก
- 01_Turnaround/         5 มุมมองรอบตัว
- 02_Expressions/        8 สีหน้าอารมณ์ (ครึ่งตัว)
- 03_Poses/              8 ท่าทาง (เต็มตัว)
